# 🗺️ Peta Folder Dompet Kita

Agar Sayang tidak bingung, ini adalah peta rumah digital kita yang baru. Semuanya sudah dikelompokkan sesuai fungsinya! 🏠✨

```text
Dompet Kita/
├── 📱 frontend/              # Tampilan aplikasi (React + Vite)
│   ├── src/                  # Kode sumber tampilan
│   ├── public/               # Gambar & aset publik
│   └── package.json          # Resep masakan frontend
│
├── ⚙️ backend/               # Otak & Brankas (Laravel 11)
│   ├── app/                  # Logika bisnis (Controller & Model)
│   ├── database/             # Cetakan tabel (Migrations)
│   ├── routes/               # Pintu masuk data (API)
│   └── .env                  # Rahasia dapur backend
│
├── 🏛️ mcp-server/            # Sistem lama (Legacy) / Jembatan AI
│
├── 📄 docs/                  # Perpustakaan dokumen
│   ├── RULES.md              # Aturan main
│   ├── SECURITY_SYSTEM.md    # Detail keamanan
│   └── FOLDER_STRUCTURE.md   # Peta ini!
│
├── 📦 package.json           # Remote Control utama (Root)
└── 📘 README.md              # Buku panduan utama
```

### 🎮 Cara Mengendalikan (Root Commands)

Sayang tidak perlu masuk-keluar folder. Cukup dari folder utama, jalankan:

1.  **Jalankan Frontend**: `npm run dev`
2.  **Jalankan Backend**: `npm run backend`
3.  **Update Semua**: `npm run update-all`
